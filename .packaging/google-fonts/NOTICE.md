# Self-hosted Google Fonts

Added by Stateloop packaging so players' browsers never contact Google. The files are the exact
stylesheets and WOFF2 files Google Fonts serves for the game's own font request; each family keeps
its licence from google/fonts at 2fe1e8c6b137fb13041a7cfca6fdcd8a910ea4dc.

- DM Sans: OFL-1.1 (google/fonts `ofl/dmsans/OFL.txt`)
- Manrope: OFL-1.1 (google/fonts `ofl/manrope/OFL.txt`)
- Playfair Display: OFL-1.1 (google/fonts `ofl/playfairdisplay/OFL.txt`)

Source stylesheets:

- `https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600&family=Manrope:wght@500;600;700&family=Playfair+Display:ital,wght@0,400;1,400&display=swap` (sha256 78b99a0ddcf9f95211e426d0e62619a253ca9014be3bd705507dbbbd028830ba)
